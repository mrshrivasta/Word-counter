# 📌 Overview

Word Counter Pro is a high-performance, privacy-focused content optimization platform built using:

- Python
- Flask
- Local NLP pipelines
- Statistical text analysis
- Real-time scoring engines

Unlike cloud-based writing tools, Word Counter Pro is:

✅ AI-Free  
✅ Offline-first  
✅ Privacy-first  
✅ Local-only  
✅ Zero telemetry  
✅ Ultra-fast  

Everything runs locally on your machine.

No cloud APIs.  
No tracking.  
No subscriptions.  
No data collection.

# 📥 Installation Guide

# 🐍 Step 1 — Install Python

Download Python:

🔗 https://www.python.org/downloads/

IMPORTANT:

Enable:

```txt
Add Python to PATH
```

---

# 📦 Step 2 — Clone Repository

```bash
git clone https://github.com/mrshrivasta/Word-counter.git
```

---

# 📁 Step 3 — Open Project Folder

```bash
cd Word-counter
```

---

# 📦 Step 4 — Install Requirements

```bash
pip install -r requirements.txt
```

---

# 🧠 Step 5 — Download NLP Data

Run:

```bash
python -c "import nltk; nltk.download('punkt'); nltk.download('stopwords'); nltk.download('punkt_tab'); nltk.download('averaged_perceptron_tagger_eng')"
```

---

# 🚀 Step 6 — Run Application

```bash
python run.py
```

---

# 🌐 Step 7 — Open Browser

```txt
http://127.0.0.1:5000
```

---

# ⚡ Quick Start

```bash
pip install -r requirements.txt
python run.py
```
